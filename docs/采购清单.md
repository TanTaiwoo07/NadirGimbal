## 已有物料（不用买）

- 相机：AR0234 USB 全局快门（约 100 g）——装到内框后用减震球+IMU 数据做软件稳像
- 飞控：PIX2.4.8（ArduPilot 4.6/4.7）——只通过 2 路 PWM 给云台下目标角
- 6S 主电池 + 3S 小电池——BEC 从 6S 取电
- 机架自带减震板——机体侧 IMU 装在减震板之下、相机侧 IMU 随内框
